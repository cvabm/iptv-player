# Release signing (public)

This project ships a **public** release keystore for CI and local release builds.
Do **not** use it for Play Store apps that need private signing.

| Field | Value |
|-------|-------|
| File | `iptv-release.jks` |
| Store password | `iptvplayer` |
| Key alias | `iptvplayer` |
| Key password | `iptvplayer` |
| Validity | 10000 days |
